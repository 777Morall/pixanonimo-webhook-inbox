# Segurança

Projeto público de exemplos do [PixAnonimo.net](https://pixanonimo.net).

## Relatar um problema

Use a opção **Security → Report a vulnerability** deste repositório para enviar
uma reprodução mínima com dados artificiais. Não publique tokens, chaves,
credenciais, dados pessoais ou detalhes de contas reais em issues ou pull requests.

## Escopo

Os testes e exemplos devem rodar localmente. Este repositório não autoriza
testes contra contas, serviços ou infraestrutura de terceiros. Nenhuma
credencial de produção é necessária.

O suporte técnico deste código está limitado à versão atual da branch principal.
Confira o código e os limites documentados antes de adaptar os exemplos.

Informações públicas da plataforma: https://pixanonimo.net/seguranca
